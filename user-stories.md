# Hide and seek user stories

Each story is one player action. The rules and numbers are in the requirements, and they are not repeated here.

## Set up a match

As a host, I want to start a match without an account, so that we can play as soon as both phones are together.

As a host, I want to pick small, medium, or large, so that the match uses that size's settings.

As a player, I want my changes to those settings saved on my phone, so that the next match I host starts from them.

As the joining team, I want this match to use the host's size and settings, so that my own saved settings do not change it.

As the other team, I want to join with a code or a QR code, so that I can join from nearby or from a code.

As a host, I want to search a city and use its boundary as the play border, so that I do not draw the border.

As a host, I want stations inside that border grouped by mode, with metro and train on and bus off, so that I can turn a whole group on or off.

As a host, I want to remove one station or add one the search missed, so that I can correct the list.

As a host, I want to place an added station by moving the map under a crosshair, so that my finger does not hide the point.

As a host, I want the chosen stations to be the possible hiding zones, so that the hider's zone will be one of them. Seekers can see every zone and never see which one was chosen.

As a host, I want the station list behind a toggle, so that I can open it.

## Hiding period

As either team, I want a hiding countdown from the start, and an alert when it ends, so that we both know when seeking begins.

As a hider, I want the app to choose the nearest marked station when that countdown ends, so that I do not pick one myself.

## Play the map

As a hider, I want to see the seekers, so that I know where they are.

As a seeker, I want the hiders hidden, so that I have to find them.

As either team, I want the app to know both positions, so that it can calculate answers and notice endgame.

As a hider, I want a warning if someone leaves the border, with tracking still on, so that leaving does not silently end the game.

## Questions

As a seeker, I want to ask one question at a time, from matching, measuring, thermometer, radar, or photos, so that we are never answering two at once.

As a hider, I want to see the calculated answer and its countdown, so that I know the result and how long I have.

As a hider, I want that calculated answer locked, so that I cannot change it.

As a hider, I want to send the answer or hold it, so that I decide when the seekers learn it.

As a hider, I want my hiding clock to pause if the countdown runs out, and a reminder that this answer draws no card, so that the delay is not hiding time.

As a hider, I want a reminder of how many physical cards to draw and keep after an on-time answer, so that the deck stays in our hands.

As either team, I want an asked question greyed out in its list, so that we can see it was used.

## The possible area

As either team, I want a sent answer to update the shared area, so that we see the same search.

As either team, I want a yes to keep the inside of the circle and a no to grey it out, so that the map matches the answer.

As either team, I want a held answer to leave the map unchanged, so that silence is not treated as a fact.

As either team, I want a plan view of yes and no before a question is asked, and a live view of sent answers only, so that planning stays separate from the game.

## Photos and video

As either team, I want to send a photo or a short video with a question or on its own, so that we can show what we see.

As a hider, I want an ordinary answer to send without a photo, so that a picture is not required every time.

As a hider, I want a photo question to open the camera, and a preview where I can crop or retake, so that I control the picture before it is sent.

## Endgame and scoring

As a hider, I want a notification and a marker when a seeker enters my zone, so that I know endgame has started.

As a seeker, I want no sign that endgame started, so that I do not learn I am in the right zone.

As either team, I want to switch who hides for as many rounds as we want, so that each team can try again.

As either team, I want each team's longest hiding time shown, so that the longer time is the winner.

As a host, I want optional time limits for a round and for the whole game, so that we can stop on a schedule.

As a hider, I want to end a round with Found, so that we stop when the seekers see us.

As a seeker, I want standing nearby to never count as a win, so that we have to actually see each other.

## Later
